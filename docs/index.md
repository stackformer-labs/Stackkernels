# StackKernels Documentation

This documentation provides guides, API references, and architecture details for StackKernels, a collection of fused Triton kernels for transformer models with PyTorch and JAX bindings.

---

## What is StackKernels?

StackKernels is a library of fused GPU kernels written in OpenAI Triton, designed for transformer training and inference. It provides direct drop-in replacements for core neural network operations—including RMSNorm, LayerNorm, SwiGLU, Rotary Position Embeddings (RoPE), FlashAttention, and fused Linear Cross-Entropy.

The library was created for the Stackformer architecture but can be used as a standalone dependency in any PyTorch or JAX project.

---

## Key Capabilities

- **Kernel Fusion**: Combines multi-step operations (such as residual addition and normalization, gated activations, or linear projection with cross-entropy) into single-pass GPU kernels, eliminating redundant global memory reads and writes.
- **Dual Framework Support**: Provides clean, autograd-compatible frontends for both PyTorch (`torch.autograd.Function`, `nn.Module`) and JAX (`custom_vjp`, `triton_call`).
- **Device-Aware Optimization Layer**: Analyzes hardware attributes (streaming multiprocessors, register files, shared memory limits) and compiler metadata to determine block sizes, warp counts, and pipeline stages without runtime guesswork.
- **Transparent Fallback**: Automatically routes execution to pure PyTorch or JAX reference implementations when running on CPU or unsupported hardware, ensuring test suites and debugging run everywhere without code changes.
